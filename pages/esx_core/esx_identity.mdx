# esx_identity
A script that allows the player to pick their characters name, gender, height and date of birth. Used by `es_extended`

## Commands
<Callout type="info">
    These commands are available only while the ```Config.EnableDebug``` option is turned on in the ```es_extended``` config file
</Callout>

```char```

This command show the identity of the current active character.

```chardel```

This command deletes the character currently in use.
