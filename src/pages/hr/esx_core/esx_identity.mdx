# esx_identity
Skript koji omogućuje igraču da odabere ime svog lika, spol, visinu i datum rođenja. Koristi se u `es_extended`.

### Prikaži izbornik za registraciju identiteta
Prikazivanje izbornika za registraciju identiteta.

**Primjer**
```lua
TriggerEvent("esx_identity:showRegisterIdentity")
```

### Slušanje kada igrač završi registraciju identiteta
Slušanje kada igrač završi registraciju identiteta. Samo server strana.

**Primjer**
```lua
AddEventHandler("esx_identity:completedRegistration", function(source, data)
  print("Igrač sa id-em " .. source .. " registrirao je svoj identitet. I zove se " .. data.firstname .. " " .. data.lastname)
end)
```
