# Server side Eventi
Ova stranica sadrži sve evente server strane koje pruža es_extended

## Event Triggeri
<Callout type="info">
    Ovi eventi mogu biti triggerani od strane bilo koje skripte. 
</Callout>



## Event Handleri
<Callout type="warning">
    Ovi eventi se mogu samo slušati i **ne bi trebali** biti triggerani. Ako se to ipak učini, doći će do do **kvara** skripti
</Callout>

### esx:playerLoaded
Ovaj event se triggera kada je igrač uspješno učitan / kada je lik odabran i učitan.

**Argumenti**
<OutputTable rows={[
    { arg: "playerId", type: "number", description: "ID igrača." },
    { arg: "xPlayer", type: "string", description: "xPlayer objekt igrača koji se povezao." },
    { arg: "isNew", type: "boolean", description: "Je li lik igrača nov." }
]}/>

**Primjer**
```lua
AddEventHandler('esx:playerLoaded', function (playerId, xPlayer, isNew)
    if isNew then
        print("Novi lik " .. xPlayer.getName() .. " je uspješno učitan s ID-jem igrača: " .. playerId)
    else
        print(xPlayer.getName() .. " je uspješno učitan s ID-jem igrača: " .. playerId)
    end
end)
```

### esx:playerLogout

### esx:onAddInventoryItem
Triggera se kada se doda stavka u inventar.

**Povratne vrijednosti**
<OutputTable rows={[
    { arg: "source", type: "number", description: "ID igrača." },
    { arg: "itemName", type: "string", description: "Stavka koja je dodana." },
    { arg: "itemCount", type: "number", description: "Količina koju igrač sada ima." }
]}/>

**Primjer**
```lua 
AddEventHandler('esx:onAddInventoryItem', function(source, itemName, itemCount)
    local xPlayer = ESX.GetPlayerFromId(source)
    print(xPlayer.getName() .. " je dobio " .. itemName .. " i sada ima " .. itemCount)
end)
```

### esx:onPlayerDeath
Ovaj event se triggera kada igrač umre

**Podaci**
<OutputTable isTable={true} rows={[
    { arg: "victimCoords", type: "vector3", description: "Koordinate žrtve." },
    { arg: "killerCoords", type: "vector3", description: "Koordinate ubojice." },
    { arg: "distance", type: "number", description: "Udaljenost između žrtve i ubojice." },
    { arg: "killedByPlayer", type: "boolean", description: "Je li ubojica igrač." },
    { arg: "deathCause", type: "string", description: "Uzrok smrti." },
    { arg: "killerServerId", type: "number", description: "Server ID ubojice." },
    { arg: "killerClientId", type: "string", description: "Lokalni ID ubojice." },
]}/>

**Primjer**
```lua
RegisterNetEvent('esx:onPlayerDeath', function (data)
    print(string.format("%s je ubijen od strane %s s udaljenosti od %s metara.", source, data.killerServerId, data.distance))
end)
```
