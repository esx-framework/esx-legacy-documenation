## RegisterServerCallback
This function registers a server callback, which is used for sending Server Data, to a client.

See [*TriggerClientCallback*](../client/functions/#triggerservercallback)

**Arguments**
<ArgumentsTable rows={[
    { arg: "name", type: "string", description: "The server callback's name." },
    { arg: "cb", type: "function", description: "The callback." },
    { arg: "...", type: "arguments", description: "The callback's argument." },
]} />

**Example**
```lua
local myMemeServer = 'Meme data string'
-- The first argument of the handler function is the player source (NetID),
-- cb is the callback function we call when we want to return data to client
-- subsequent parameters were the arguments called from the client.
ESX.RegisterServerCallback('myScript:getMeme', function(src, cb, param1, param2)
  -- Logic needed to derive whatever data you would like to send back
  -- using the passed params on the handler (src, param1, param2, etc)

  -- Send back our meme data to client handler
  cb(myMemeServer)
end)
```

## TriggerClientCallback
This function triggers a client callback, which is used to get data from the client.

<Callout type="warning">
    This should be used with caution! You should never trust data from the client.
    So don't use it to get sensitive data, like money amount the player should receive.
</Callout>

**Arguments**
<ArgumentsTable rows={[
    { arg: "player", type: "number", description: "The client to trigger the callback for." },
    { arg: "eventName", type: "string", description: "The callback name to trigger." },
    { arg: "cb", type: "function", description: "The callback to trigger when data get's send back." },
    { arg: "...", type: "arguments", description: "The callback arguments that should be send to the client." },
]} />

**Example**
```lua
ESX.TriggerClientCallback(player, "esx:GetVehicleType", function(vehicleType)
	print("The bati is a " .. vehicleType) -- "The bati is a bike"
end, "bati")
```

## RegisterCommand
This function registers a command.

**Arguments**
<ArgumentsTable rows={[
    { arg: "name", type: "string | table", description: "The name of the command." },
    { arg: "group", type: "string | table", description: "The groups able to run this command." },
    { arg: "cb", type: "function", description: "The callback function that gets ran." },
    { arg: "allowConsole", type: "boolean", optional: true, description: "Is it allowed for the command to be ran through console." },
    { arg: "suggestion", type: "table", optional: true, description: "Chat suggestion data." }
]} />

**Callback**
<OutputTable rows={[
    { arg: "xPlayer", type: "table", description: "The xPlayer table of the client." },
    { arg: "args", type: "table", description: "The arguments the player has put in." },
    { arg: "showError", type: "function", description: "Print or show a notification." }
]}/>

**Suggestion**
<ArgumentsTable rows={[
    { arg: "help", type: "string", description: "The help message shown in the chat." },
    { arg: "arguments", type: "table", description: "The arguments the player can put in." }
]}/>

**Suggestion Arguments**
<ArgumentsTable isTable={true} rows={[
    { arg: "name", type: "string", description: "The argument key." },
    { arg: "help", type: "string", description: "Explanation of the argument." },
    { arg: "type", type: "string", description: "Type of the argument. Possible Types: number, playerId, string, item, weapon, any, merge, coordinate." },
]}/>

**Example**
```lua
ESX.RegisterCommand({'cardel', 'dv'}, 'admin', function(xPlayer, args, showError)
  if not args.radius then args.radius = 4 end
  xPlayer.triggerEvent('esx:deleteVehicle', args.radius)
end, false, {
    help = _U('command_cardel'), 
    arguments = {
        name = 'radius', 
        help = _U('command_cardel_radius'), 
        type = 'any'
    }
})
```

## GetExtendedPlayers
This function returns all loaded xPlayers and if a filter is applied that match the filter. 

**Arguments**
<ArgumentsTable rows={[
    { arg: "key", optional: true, type: "string", description: "The key to filter players from" },
    { arg: "val", optional: true, type: "any", description: "The value to filter from." }
]} />

**Returns**

A table with the xPlayer objects.

**Example**
```lua
local policeOfficers = ESX.GetExtendedPlayers('job', 'police')

for i, xPlayer in ipairs(policeOfficers) do
    print("Found Officer with " .. xPlayer.getJob().grade_label .. " rank.")
end
```

## RegisterPlayerFunctionOverrides
With this function you can override existing functions in the player object or add new ones.

<Callout type="warning">
    Please note, only one override can be active at a time. Ensure no other scripts are using this function simultaneously. This limitation may be lifted in future updates.
</Callout>

**Arguments**
<ArgumentsTable rows={[
    { arg: "index", type: "string", description: "The overrides index." },
    { arg: "overrides", type: "table", description: "The table with the functions to be overriden with." },
]} />

**Example**
```lua
local LeoJobs = { "police", "sheriff", "fib" }
local FireJobs = { "ambulance", "doctor", "firefighter" }
ESX.RegisterPlayerFunctionOverrides("myOverrides", {
    isLeo = function(self)
        return table.contains(LeoJobs, self.job.name)
    end,
    isMedic = function(self)
        return table.contains(FireJobs, self.job.name)
    end
})
```

## DoesJobExist
This function returns if the specified job and grade exist.

**Arguments**
<ArgumentsTable rows={[
    { arg: "job", type: "string", description: "The name of the job." },
    { arg: "grade", type: "number", description: "The grade index of the job." }
]} />

**Returns**

Returns a boolean if the given job and grade exist.
<OutputTable rows={[
    { arg: "exists", type: "boolean", description: "Does the job and grade exist." },
]}/>

**Example**
```lua
local xPlayer = ESX.GetPlayerFromId(source)
local Job = 'police'
local Grade = 4 -- highest police grade

if ESX.DoesJobExist(Job, Grade) then -- make sure the Job and Grade are both defined in the database
  xPlayer.setJob(Job, Grade)
end
```
