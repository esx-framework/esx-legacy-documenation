## RegisterServerCallback
Ova funkcija registrira server callback, koji se koristi za slanje podataka servera klijentu.

Pogledajte [*TriggerClientCallback*](../client/functions/#triggerservercallback)

**Argumenti**
<ArgumentsTable rows={[
    { arg: "name", type: "string", description: "Naziv server callback-a." },
    { arg: "cb", type: "function", description: "Callback funkcija." },
    { arg: "...", type: "arguments", description: "Argumenti callback funkcije." },
]} />

**Primjer**
```lua
local myMemeServer = 'Meme data string'
-- Prvi argument handler funkcije je source igrača (NetID),
-- cb je callback funkcija koju zovemo kada želimo vratiti podatke klijentu
-- sljedeći parametri su argumenti pozvani od strane klijenta.
ESX.RegisterServerCallback('mojaSkripta:getMeme', function(src, cb, param1, param2)
  -- Logika potrebna za dobivanje podataka koje želite poslati natrag
  -- koristeći proslijeđene parametre u handleru (src, param1, param2, itd.)

  -- Pošaljite naše meme podatke natrag klijentskom handleru
  cb(myMemeServer)
end)
```

## TriggerClientCallback
Ova funkcija aktivira klijentski callback, koji se koristi za dobivanje podataka od klijenta.

<Callout type="warning">
    Ovo treba koristiti s oprezom! Nikada ne biste trebali vjerovati podacima od klijenta.
    Zato ih nemojte koristiti za dobivanje osjetljivih podataka, poput iznosa novca koji igrač treba dobiti.
</Callout>

**Argumenti**
<ArgumentsTable rows={[
    { arg: "player", type: "number", description: "Klijent za kojeg se aktivira callback." },
    { arg: "eventName", type: "string", description: "Naziv callback-a koji se aktivira." },
    { arg: "cb", type: "function", description: "Callback funkcija koja se aktivira kada podaci budu poslani natrag." },
    { arg: "...", type: "arguments", description: "Argumenti callback funkcije koji se trebaju poslati klijentu." },
]} />

**Primjer**
```lua
ESX.TriggerClientCallback(player, "esx:GetVehicleType", function(vehicleType)
	print("Bati801 je " .. vehicleType) -- "Bati801 je motor"
end, "bati")
```

## RegisterPlayerFunctionOverrides
S ovom funkcijom možete nadjačati postojeće funkcije u objektu igrača ili dodati nove.

<Callout type="warning">
    Napomena: samo jedno nadjačavanje može biti aktivno u isto vrijeme. Osigurajte da nijedna druga skripta ne koristi ovu funkciju istovremeno. Ovo ograničenje može biti uklonjeno u budućim ažuriranjima
</Callout>

**Argumenti**
<ArgumentsTable rows={[
    { arg: "index", type: "string", description: "Indeks nadjačavanja." },
    { arg: "overrides", type: "table", description: "Tablica s funkcijama koje treba nadjačati." },
]} />

**Primjer**
```lua
local LeoJobs = { "police", "sheriff", "fib" }
local FireJobs = { "ambulance", "doctor", "firefighter" }
ESX.RegisterPlayerFunctionOverrides("myOverrides", {
    isLeo = function(self)
        return table.contains(LeoJobs, self.job.name)
    end,
    isMedic = function(self)
        return table.contains(FireJobs, self.job.name)
    end
})
```

## DoesJobExist
Ova funkcija provjerava postoji li određeni posao i razina.

**Argumenti**
<ArgumentsTable rows={[
    { arg: "job", type: "string", description: "Ime posla." },
    { arg: "grade", type: "number", description: "Indeks čina posla." }
]} />

**Povratne informacije**

Vraća boolean vrijednost ako određeni posao i razina postoje.
<OutputTable rows={[
    { arg: "exists", type: "boolean", description: "Postoji li posao i razina." },
]}/>

**Primjer**
```lua
local xPlayer = ESX.GetPlayerFromId(source)
local Job = 'police'
local Grade = 4 -- najviša razina policije

if ESX.DoesJobExist(Job, Grade) then -- provjerava postoje li posao i razina u bazi podataka
  xPlayer.setJob(Job, Grade)
end
```
