# Serverske OneSync funkcije
Funkcije koje se koriste za dobivanje podataka koji su inače dostupni na klijentu. I funkcije za stvaranje sinkroniziranih entiteta.

## GetPlayersInArea
Ova funkcija dobiva sve igrače u zadanom radijusu.

**Argumenti**
<ArgumentsTable rows={[
    { arg: "playerId", type: "number", optional: false, description: "ID igrača od kojeg želite dobiti bliske igrače" },
    { arg: "radius", type: "number", optional: true, defaultValue: '100', description: "Radijus za pretraživanje igrača" },
    { arg: "ignore", type: "table", optional: true, description: "Tablica s ID-ovima servera koji se trebaju ignorirati" },
]} />

**Povratne vrijednosti**

Ova funkcija će vratiti **`table`** s podacima ili praznu **`table`** ako nijedan igrač nije pronađen.
<OutputTable isTable={true} rows={[
    { arg: "id", type: "number", description: "ID igrača" },
    { arg: "ped", type: "string", description: "Ped handle igrača" },
    { arg: "coords", type: "vector3", description: "Koordinate igrača" },
    { arg: "dist", type: "number", description: "Udaljenost do igrača" }
]}/>

**Primjer**
```lua
local playersInArea = ESX.OneSync.GetPlayersInArea(1, 10.0, {
    [1] = true -- isključuje igrača s ID-om 1
})

for i=1, #playersInArea do
    local player = playersInArea[i] 
end 
```

## SpawnVehicle 
Ova funkcija će stvoriti vozilo s server setterom, što znači da će vozilo pripadati serveru i neće biti uklonjeno kada nema aktivnih klijenata.

<Callout type="warning">
    Ako nema igrača u radijusu od 300 od koordinata, vozilo se NEĆE stvoriti.
    Također, deformacija vozila više neće biti sinkronizirana kada nema igrača u njegovom opsegu.
</Callout>

**Argumenti**
<ArgumentsTable rows={[
    { arg: "model", type: "string", optional: false, description: "Model koji želite stvoriti" },
    { arg: "coords", type: "number", optional: false, description: "Koordinate na kojima želite stvoriti vozilo" },
    { arg: "heading", type: "number", optional: false, description: "Orijentacija s kojom želite stvoriti vozilo" },
    { arg: "properties", type: "table", optional: false, description: "Svojstva vozila"}, 
    { arg: "cb", type: "function", optional: false, description: "Povratna funkcija"}
]} />

**Primjer**
```lua
ESX.OneSync.SpawnVehicle('blista', vector3(0, 0, 0), 0, {}, function(networkId)     
    local vehicle = NetworkGetEntityFromNetworkId(networkId)
end)  
```

## SpawnPedInVehicle 
Ova funkcija će stvoriti ped unutar vozila.

**Argumenti**
<ArgumentsTable rows={[
    { arg: "model", type: "string", optional: false, description: "Model koji želite stvoriti" },
    { arg: "vehicle", type: "number", optional: false, description: "Handle vozila u kojem ped treba biti stvoren" },
    { arg: "seat", type: "number", optional: false, description: "Sjedalo na kojem ped treba biti smješten" },
    { arg: "cb", type: "function", optional: false, description: "Povratna funkcija"}
]} />

**Primjer**
```lua
local vehicles = GetAllVehicles()

if #vehicles < 1 then return end 
ESX.OneSync.SpawnPedInVehicle('a_f_m_beach_01', vehicles[math.random(1, #vehicles)], -1, function(networkId)
    local ped = NetworkGetEntityFromNetworkId(networkId) 
end)
```

## GetPedsInArea 
Ova funkcija će dobiti sve ped-ove u zadanom području.

**Argumenti**
<ArgumentsTable rows={[
    { arg: "coords", type: "vector3", optional: false, description: "Koordinate područja" },
    { arg: "radius", type: "number", optional: false, description: "Radijus za pretraživanje ped-ova" },
    { arg: "modelFilter", type: "table", optional: false, description: "Tablica s modelima koji se trebaju ignorirati" },
]} />

**Povratne vrijednosti**

Ova funkcija će vratiti **`tablu`** s network ID-ovima pronađenih ped-ova.


**Primjer**
```lua
local peds = ESX.OneSync.GetPedsInArea(vector3(0,0,0), 30.0, {
    [joaat('a_f_m_beach_01')] = true -- joaat je funkcija u lua v5.4 koja vraća hash
})

for i=1, #peds do 
    local ped = NetworkGetEntityFromNetworkId[peds[i]] 
end 
```
