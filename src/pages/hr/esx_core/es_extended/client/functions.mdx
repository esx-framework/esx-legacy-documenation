# Functions 
This topic includes most functions that are existing in ESX. 

## IsPlayerLoaded 
This function will return a `bool` if the player has sucessfully loaded.
This should be checked before manipulating or checking data of the player.

**Example** 
```lua
while not ESX.IsPlayerLoaded() do 
    Wait(250) 
end 

print('player is loaded') 
```

## GetPlayerData
This function simply returns ESX.PlayerData.

**Example**
```lua
local playerData = ESX.GetPlayerData()

print("The client's identifier: " .. playerData.identifier)
```

## ShowAdvancedNotification
This function will show a default GTA 5 notification 

**Arguments** 
<ArgumentsTable rows={[
    { arg: 'sender', type: 'string', description: 'The notification title.' }, 
    { arg: 'subject', type:'string', description: 'The notification subtitle'},
    { arg: 'msg', type: 'string', description: 'The notification message'}, 
    { arg: 'textureDict', type: 'string', description: 'The texture dictionary for the icon'}, 
    { arg: 'iconType', type: 'string', description: 'The icon type, see the list below.'}, 
    { arg: 'flash', type: 'boolean', optional: true, defaultValue: 'false', description: 'According to the fivem natives, this var never works no matter what.'},  
    { arg: 'saveToBrief', type: 'boolean', optional: true, defaultValue: 'false', description: 'Makes the notification appear in the "Pause Menu > Info/Brief > Notifications" section.'}, 
    { arg: 'hudColorIndex', type: 'number', optional: true, description: 'The background color for the notification.'}
]} />

**Icon types**
1. Chat Box  
2. Email  
3. Add Friend Request  
4. Nothing  
5. Nothing  
6. Nothing  
7. Right Jumping Arrow  
8. RP Icon  
9. $ Icon 

**[Hud color indexes](https://docs.fivem.net/docs/game-references/hud-colors/)**

**Example** 
```lua
local handle = RegisterPedheadshot(PlayerPedId())
while not IsPedheadshotReady(handle) or not IsPedheadshotValid(handle) do
    Wait(0)
end
local txd = GetPedheadshotTxdString(handle)
local title = GetPlayerName(PlayerId())
local subtitle = 'Private Message'
local iconType = 0
ESX.ShowAdvancedNotification(title, subtitle, 'this is the message that we send to you', txd, iconType, false, true, 6)
```

## ShowHelpNotification
This function shows a help notification on the top left of the screen. 
Either needs to be ran every frame or a duration can be optionally set.

**Arguments**
<ArgumentsTable rows={[
    { arg: 'msg', type: 'string', description: 'The message content.' }, 
    { arg: 'thisFrame', type: 'boolean', optional: true, defaultValue: 'false', description: 'Should it only be displayed this frame.' },
    { arg: 'beep', type: 'boolean', optional: true, defaultValue: 'false', description: 'Should it play a beep sound?' },
    { arg: 'duration', type: 'number', optional: true, defaultValue: '-1', description: 'The duration of how long this should show.' }
]} /> 

**Example** 
```lua
RegisterCommand('help', function (source, args, raw)
    ESX.ShowHelpNotification("We won't give you help, we are truly not sorry.", false, true, 3500)
end)
```

## ShowFloatingHelpNotification 
This function shows a floating help notification, this is needs to be ran every millisecond.

**Arguments**
<ArgumentsTable rows={[
    { arg: 'msg', type: 'string', description: 'The floating message.' }, 
    { arg: 'coords', type: 'vector3', description: 'The coords of where it should be displayed' }
]} /> 

**Example** 
```lua
local coords = vector3(0, 0, 0) 

CreateThread(function() 
    while true do
        ESX.ShowFloatingHelpNotification('ESX is so cool', coords) 
        Wait(0) 
    end 
end)
```

## HashString
This function will turn a string into a (rockstar) hash. Which for example could be used to display a key of a custom keybind.

**Arguments**
<ArgumentsTable rows={[
    { arg: 'str', type: 'string', description: 'The string that should be hashed.' }
]} />

**Example** 
```lua
RegisterCommand('howtosit', function (source, args, raw)
    local inputMapping = string.format("~INPUT_%s~"):format(ESX.HashString("sit"))
    ESX.ShowHelpNotification("You can sit down using "..inputMapping , false, true, 3500)
end)
```

**Arguments** 
<ArgumentsTable rows={[

**Example**

```lua
    print('pressed')
end, function() 
    print('released')
end)  
```
