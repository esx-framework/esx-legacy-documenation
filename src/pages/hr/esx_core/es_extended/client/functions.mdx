# Funkcije 
Ova sekcija sadrži funkcije ESX-a. 

## IsPlayerLoaded 
Ova funkcija će vratiti `bool` je li se igrač učitao.
Ovo biste trebali provjeriti prije mjenjanja ili provjeravanja podataka igrača

**Primjer** 
```lua
while not ESX.IsPlayerLoaded() do 
    Wait(250) 
end 

print('igrač je učitan') 
```

## GetPlayerData
Ova funkcija vraća objekt ESX.PlayerData.

**Primjer**
```lua
local playerData = ESX.GetPlayerData()

print("Igračev identifier je: " .. playerData.identifier)
```

    { arg: 'iconType', type: 'string', description: 'Tip ikone, pogledaj ispod.'}, 
    { arg: 'flash', type: 'boolean', optional: true, defaultValue: 'false', description: 'Prema FiveM dokumentaciji, ovo ništa ne radi.'},  
    { arg: 'saveToBrief', type: 'boolean', optional: true, defaultValue: 'false', description: 'Prikazuje notifikaciju u "Pause Menu > Info/Brief > Notifications" sekciji u GTA.'},

2. Email  
3. Add Friend Request  
4. Ništa  
5. Ništa  
6. Ništa  
7. Right Jumping Arrow  
8. RP Ikona  
9. $ Ikona

**Primjer** 
```lua
local handle = RegisterPedheadshot(PlayerPedId())
```
