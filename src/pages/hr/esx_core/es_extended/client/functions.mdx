# Funkcije 
Ova sekcija sadrži funkcije ESX-a. 

## IsPlayerLoaded 
Ova funkcija će vratiti `bool` je li se igrač učitao.
Ovo biste trebali provjeriti prije mjenjanja ili provjeravanja podataka igrača

**Primjer** 
```lua
while not ESX.IsPlayerLoaded() do 
    Wait(250) 
end 

print('igrač je učitan') 
```

## GetPlayerData
Ova funkcija vraća objekt ESX.PlayerData.

**Primjer**
```lua
local playerData = ESX.GetPlayerData()

print("Igračev identifier je: " .. playerData.identifier)
```

## ShowAdvancedNotification
Ova funkcija prikazuje obične GTA notifikacije 

**Argumenti** 
<ArgumentsTable rows={[
    { arg: 'sender', type: 'string', description: 'Naslov notifikacije.' }, 
    { arg: 'subject', type:'string', description: 'Podnaslov notifikacije'},
    { arg: 'msg', type: 'string', description: 'Poruka notifikacije'}, 
    { arg: 'textureDict', type: 'string', description: 'Texture dictionary notifikacije'}, 
    { arg: 'iconType', type: 'string', description: 'Tip ikone, pogledaj ispod.'}, 
    { arg: 'flash', type: 'boolean', optional: true, defaultValue: 'false', description: 'Prema FiveM dokumentaciji, ovo ništa ne radi.'},  
    { arg: 'saveToBrief', type: 'boolean', optional: true, defaultValue: 'false', description: 'Prikazuje notifikaciju u "Pause Menu > Info/Brief > Notifications" sekciji u GTA.'}, 
    { arg: 'hudColorIndex', type: 'broj', optional: true, description: 'Boja pozadine u notifikaciji.'}
]} />

**Tipovi ikone**
1. Chat Box  
2. Email  
3. Add Friend Request  
4. Ništa  
5. Ništa  
6. Ništa  
7. Right Jumping Arrow  
8. RP Ikona  
9. $ Ikona  

**[Boje](https://docs.fivem.net/docs/game-references/hud-colors/)**

**Primjer** 
```lua
local handle = RegisterPedheadshot(PlayerPedId())
while not IsPedheadshotReady(handle) or not IsPedheadshotValid(handle) do
    Wait(0)
end
local txd = GetPedheadshotTxdString(handle)
local title = GetPlayerName(PlayerId())
local subtitle = 'Privatna poruka'
local iconType = 0
ESX.ShowAdvancedNotification(title, subtitle, 'ovo je poruka koju vam šaljemo', txd, iconType, false, true, 6)

    end

```

<ArgumentsTable rows={[
