# UI
This topic explains the existing functions implemented by esx to create different types of ui.

## Menu
ESX offers multiple menu's by default; `esx_menu_default`, `esx_menu_dialog` and `esx_menu_list`. But we offer functions to create your own menu, they are listed below.

### RegisterType
Register a custom Menu Type

**Arguments**
<ArgumentsTable rows={[
    { arg: 'type', type: 'string', description: 'The menu key for the type.' }, 
    { arg: 'open', type: 'function', description: 'Function that gets ran when it should be opened.' },
    { arg: 'close', type: 'function', description: 'Function that gets ran when it should be closed.' },
]} /> 

**Example**
```lua
ESX.UI.Menu.RegisterType("my_menu", myOpenFunction, myCloseFunction)
```

### Open
Open menu of given type and data.

**Arguments**
<ArgumentsTable rows={[
    { arg: 'type', type: 'string', description: 'The menu key for the type.' }, 
    { arg: 'namespace', type: 'string', description: 'The namespace for the menu. (Usually script name)' }, 
    { arg: 'name', type: 'string', description: 'The name of the menu' }, 
    { arg: 'data', type: 'table', description: 'The options for the menu' }, 
    { arg: 'submit', type: 'function', description: 'The function that gets ran when triggering a button.' }, 
    { arg: 'cancel', type: 'function', description: 'The function that gets ran when canceling the menu.' }, 
    { arg: 'change', type: 'function', description: 'The function that gets ran when data changes.' }, 
    { arg: 'close', type: 'function', description: 'The function that gets ran when the menu closes.' }
]} />

**Returns**
<OutputTable rows={[
    { arg: 'type', type: 'string', description: 'The menu key for the type.' }, 
    { arg: 'namespace', type: 'string', description: 'The namespace for the menu. (Usually script name)' },
    { arg: 'resourceName', type: 'string', description: 'The script that created it or Unknown' },
    { arg: 'name', type: 'string', description: 'The name of the menu' }, 
    { arg: 'data', type: 'table', description: 'The options for the menu' },
    { arg: 'submit', type: 'function', description: 'Trigger to force the submit function.' }, 
    { arg: 'cancel', type: 'function', description: 'Trigger to force the cancel function.' }, 
    { arg: 'change', type: 'function', description: 'Trigger to force the change function.' }, 
    { arg: 'close', type: 'function', description: 'Closes the menu.' },
    { arg: 'update', type: 'function', description: 'Updates the menu.' },
    { arg: 'refresh', type: 'function', description: 'Refreshes the menu.' },
    { arg: 'setElement', type: 'function', description: 'Set element data.' },
    { arg: 'setElements', type: 'function', description: 'Set elements.' },
    { arg: 'setTitle', type: 'function', description: 'Set title of menu' },
    { arg: 'removeElement', type: 'function', description: 'Remove element by given query' }
]}/>


**Example**
```lua
RegisterCommand('testOpen', function()
    -- Using the menu from the script `esx_menu_default`
    ESX.UI.Menu.Open('default', GetCurrentResourceName(), 'my_default_menu', {
        title = "My title",
        align = 'bottom-left',
        elements = elements
    }, function(data, menu)
        print("Submit data", data, menu)
    end, function(data, menu)
        menu.close()
        print("Cancel data", data, menu)
    end, function(data, menu)
        print("Change data", data, menu)
    end, function()
        print("Closed menu")
    end)
end)
```

### Close
Close the menu of given type, namespace and name

**Arguments**
<ArgumentsTable rows={[
    { arg: 'menuType', type: 'string', description: 'The type of the menu.' }, 
    { arg: 'namespace', type: 'string', description: 'The namespace for the menu. (Usually script name)' }, 
    { arg: 'name', type: 'string', description: 'The name of the menu' }
]} /> 

**Example**
```lua
RegisterCommand('testClose', function()
    -- Using the menu from the script `esx_menu_default`
    ESX.UI.Menu.Close('default', GetCurrentResourceName(), 'my_default_menu')
end)
```

### CloseAll
Close all menu's

**Example**
```lua
RegisterCommand('closeAllMenus', function()
    ESX.UI.Menu.CloseAll()
end)
```

### GetOpened
Get Menu table of given type, namespace and name. Refer to the docs for `ESX.UI.Menu.Open` for detailed infos to the menu data.

**Arguments**
<ArgumentsTable rows={[
    { arg: 'menuType', type: 'string', description: 'The type of the menu.' }, 
    { arg: 'namespace', type: 'string', description: 'The namespace for the menu. (Usually script name)' }, 
    { arg: 'name', type: 'string', description: 'The name of the menu' }
]} /> 

**Example**
```lua
RegisterCommand('closeAllMenus', function()
    -- Using the menu from the script `esx_menu_default`
    local myMenu = ESX.UI.Menu.GetOpened('default', GetCurrentResourceName(), 'my_default_menu')

    myMenu.close() -- Close menu
end)
```

### GetOpenedMenus
Get all open menus. Refer to the docs for `ESX.UI.Menu.Open` for detailed infos to the menu data.

### IsOpen
Check if menu of given type, namespace and name is open.

**Arguments**
<ArgumentsTable rows={[
    { arg: 'menuType', type: 'string', description: 'The type of the menu.' }, 
    { arg: 'namespace', type: 'string', description: 'The namespace for the menu. (Usually script name)' }, 
    { arg: 'name', type: 'string', description: 'The name of the menu' }
]} /> 

**Example**
```lua
RegisterCommand('isMenuOpen', function()
    -- Using the menu from the script `esx_menu_default`
    if ESX.UI.Menu.IsOpen('default', GetCurrentResourceName(), 'my_default_menu') then
        print("My epic menu is open!")
    end
end)
```
