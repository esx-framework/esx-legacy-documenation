# UI
Ova stranica objašnjava postojeće funkcije koje implementira esx za stvaranje različitih tipova UI-eva

## Menu
ESX nudi više menija po defaultu; `esx_menu_default`, `esx_menu_dialog` i `esx_menu_list`. Ali mi vam nudimo funkcije za kreiranje vašeg menija.

### RegisterType
Registrira custom UI tip

**Argumenti**
<ArgumentsTable rows={[
    { arg: 'type', type: 'string', description: 'Tipka menija za vrstu.' }, 
    { arg: 'open', type: 'function', description: 'Funkcija koja se pokreće kad otvoriš meni.' },
    { arg: 'close', type: 'function', description: 'Funkcija koja se pokreće kad zatvoriš meni.' },
]} /> 

**Primjer**
```lua
ESX.UI.Menu.RegisterType("my_menu", myOpenFunction, myCloseFunction)
```

### Close
Zatvara meni zadane vrste, imenskog prostora i naziva.

**Argumenti**
<ArgumentsTable rows={[
    { arg: 'menuType', type: 'string', description: 'Tip menija.' }, 
    { arg: 'namespace', type: 'string', description: 'Imenski prostor za meni. (Tipično da se stavi ime skripte)' }, 
    { arg: 'name', type: 'string', description: 'Ime menija' }
]} /> 

**Primjer**
```lua
RegisterCommand('testClose', function()
    -- Koristi se meni skripte `esx_menu_default`
    ESX.UI.Menu.Close('default', GetCurrentResourceName(), 'my_default_menu')
end)
```

### CloseAll
Zatvara sve menije.

**Primjer**
```lua
RegisterCommand('closeAllMenus', function()
    ESX.UI.Menu.CloseAll()
end)
```

### GetOpened
Geta tablu zadanog tipa, imenskog prostora i naziva menija. Pogledaj dokumentaciju `ESX.UI.Menu.Open` za detaljne informacije.

**Argumenti**
<ArgumentsTable rows={[
    { arg: 'menuType', type: 'string', description: 'Tip menija.' }, 
    { arg: 'namespace', type: 'string', description: 'Imenski prostor za meni. (Tipično da se stavi ime skripte)' }, 
    { arg: 'name', type: 'string', description: 'Ime menija' }
]} /> 

**Primjer**
```lua
RegisterCommand('closeAllMenus', function()
    -- Koristi se meni skripte `esx_menu_default`
    local myMenu = ESX.UI.Menu.GetOpened('default', GetCurrentResourceName(), 'my_default_menu')

    myMenu.close() -- Zatvara meni
end)
```

### GetOpenedMenus
Geta sve otvorene menije. Pogledaj dokumentaciju `ESX.UI.Menu.Open` za detaljne informacije.

### IsOpen
Provjerava jel meni zadanog tipa, imenskog prostora i naziva otvoren.

**Argumenti**
<ArgumentsTable rows={[
    { arg: 'menuType', type: 'string', description: 'Tip menija.' }, 
    { arg: 'namespace', type: 'string', description: 'Imenski prostor za meni. (Tipično da se stavi ime skripte)' }, 
    { arg: 'name', type: 'string', description: 'Ime menija' }
]} /> 

**Primjer**
```lua
RegisterCommand('isMenuOpen', function()
    -- Koristi se meni skripte `esx_menu_default`
    if ESX.UI.Menu.IsOpen('default', GetCurrentResourceName(), 'my_default_menu') then
        print("Moj meni je otvoren!")
    end
end)
```
