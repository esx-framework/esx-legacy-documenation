# esx_multicharacter
Default sustav za više karaktera koji koristi `es_extended`

## Komande

### Relog
Komanda s kojom svaki igrač može ući u izbornik za odabir karaktera jednostavnim pokretanjem komande /relog.
Ova je komanda zadano upaljena, ali se može ugasiti u konfiguraciji esx_multicharacter.

**Upotreba**
`/relog`
