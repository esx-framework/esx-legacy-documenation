# skinchanger
Skripta za postavljanje i mijenjanje odjeće, dodataka i modela igrača koju koristi `es_extended`
**Dostupno samo na client strani**

### Učitaj default model
**Argumenti**
<ArgumentsTable rows={[
    { arg: 'isMale', type: 'boolean', description: 'Treba li igrač biti postavljen na muški ped?' }, 
]} /> 

**Primjer**
```lua
--- Postavi igrača na zadani muški ped (mp_m_freemode_01)
TriggerEvent('skinchanger:loadDefaultModel', true)
```

### Povuci listu postojećih komponenti
**Argumenti**
<ArgumentsTable rows={[
    { arg: 'callback', type: 'function', description: 'Povratna funkcija koja će vratiti podatke' }, 
]} /> 

**Primjer**
```lua
TriggerEvent('skinchanger:getData', function(components, maxVals)
    print(('Komponente => %s'):format(json.encode(components)))
    print(('MaxVals => %s'):format(json.encode(maxVals)))
end)
```
