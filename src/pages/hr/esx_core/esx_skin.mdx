# esx_skin
The skin managing system used by `es_extended`
**Only available on clientside**

### Get Last Skin
Get the player's last known skin

**Example**
```lua
TriggerEvent("esx_skin:getLastSkin", function(lastSkin)
    print(json.encode(lastSkin))
end)
```

### Get the current skin
Get the current skin
**Arguments**
<ArgumentsTable rows={[
    { arg: 'cb', type: 'function', description: 'Callback that should be triggered when the skin is received.' }
]} />

**Example**
```lua
ESX.TriggerServerCallback("esx_skin:getPlayerSkin", function(skin)
    if skin == nil then
        TriggerEvent("skinchanger:loadSkin", { sex = 0 }, OpenSaveableMenu)
        Wait(100)
    else
        TriggerEvent("skinchanger:loadSkin", skin)
        Wait(100)
    end
end)
```
