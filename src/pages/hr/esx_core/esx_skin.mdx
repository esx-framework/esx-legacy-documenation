# esx_skin
Sustav za upravljanje skinovima koji koristi `es_extended`
**Dostupno samo na client strani**

### Povuci zadnji skin
Povuci zadnji poznati skin igrača

**Primjer**
```lua
TriggerEvent("esx_skin:getLastSkin", function(lastSkin)
    print(json.encode(lastSkin))
end)
```

### Povuci trenutni skin
Povuci trenutni skin
**Argumenti**
<ArgumentsTable rows={[
    { arg: 'cb', type: 'function', description: 'Callback funkcija koja se poziva kada se primi skin.' }
]} />

**Primjer**
```lua
ESX.TriggerServerCallback("esx_skin:getPlayerSkin", function(skin)
    if skin == nil then
        TriggerEvent("skinchanger:loadSkin", { sex = 0 }, OpenSaveableMenu)
        Wait(100)
    else
        TriggerEvent("skinchanger:loadSkin", skin)
        Wait(100)
    end
end)
```
