# esx_notify
Sustav za obavijesti koji koristi `es_extended`
**Dostupno samo na client strani**

### ShowNotifation

**Argumenti**
<ArgumentsTable rows={[
    { arg: 'message', type: 'string', description: 'Poruka obavijesti.' }, 
    { arg: 'type', type:'string', description: 'Tip obavijesti' }, 
    { arg: 'length', type:'number', description: 'Opcije za progress bar' } 
]} />

**Tipovi obavijesti** 
- success 
- error 
- info

**ESX Primjer** 
```lua
ESX.ShowNotification('Ovo je moj novi test.', 'error', 1500) 
```
