# esx_menu_default
Izbornik tipa lista korišten od strane `es_extended`
**Dostupno samo na client strani**

### ESX.UI.Menu.Open
Otvara izbornik koji se može koristiti s tipkama sa strelicama

```lua
ESX.UI.Menu.Open(type, namespace, name, data, onSelect, cancel )
```

### onSelect

Funkcija koja se pokreće kada se odabere element, vraća `data` i `menu`, `data.current` se koristi za dobivanje trenutno odabranog elementa

**Primjer**
```lua
function(data, menu)
  --- za jednostavan element
  if data.current.name == "element1" then
    print("Element 1 odabran")
    menu.close()
  end

  -- za elemente klizača

  if data.current.name == "bread" then
    print(data.current.value)
  end
end
```
### cancel

Ova funkcija se pokreće kada se izbornik zatvori, vraća `data` i `menu`

**Primjer**
```lua
function(data, menu)
  print("Zatvaranje izbornika - " .. menu.title)
  menu.close() -- zatvori izbornik
end
```

### Primjer izbornika
```lua
    local Elements = {
        {label = "Ja sam element", name = "element1"},
        {label = "Kruh - £200", name = "bread", value = 1, type = 'slider', min = 1, max = 100},
        {label = '<span style="color:green;">Hej! Ja sam zelen!/span>', name = "green_element"}
      }

      ESX.UI.Menu.Open("default", GetCurrentResourceName(), "Example_Menu", {
        title = "Primjer izbornika", -- Naziv izbornika za prikaz korisnicima,
        align    = 'top-left', -- top-left | top-right | bottom-left | bottom-right | center |
        elements = Elements -- definirajte elemente kao unaprijed kreiranu tablicu
      }, function(data,menu) -- OnSelect funkcija
        --- za jednostavan element
        if data.current.name == "element1" then
          print("Element 1 odabran")
          menu.close()
        end

        -- za elemente klizača

        if data.current.name == "bread" then
          print(data.current.value)

          if data.current.value == 69 then
            print("Super!")
            menu.close()
          end
        end
      end, function(data, menu) -- Cancel funkcija
        print("Zatvaranje izbornika")
        menu.close() -- zatvori izbornik
      end)
```
