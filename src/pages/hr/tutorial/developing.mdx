# Kodiranje ESX skripte

## VSCode proširenja
Ima par korisnih proširenja za visual studio code da bih vam olakšali kreiranje skripte.

### [sumneko.lua](https://marketplace.visualstudio.com/items?itemName=sumneko.lua)
Napravljeno od strane sumneka, ovo je lua programski server koji sadrži `ESX VSCode` i `CfxLua` proširenja.
Preporučene postavke:
```json
"Lua.diagnostics.disable": [
  "undefined-global",
  "err-nonstandard-symbol",
  "unknown-symbol"
]
```


### [CfxLua](https://marketplace.visualstudio.com/items?itemName=overextended.cfxlua-vscode)
Proširenje koje ukljućuje sve native i funkcije FiveM-a. 
Napravljeno od strane overextended-a.

### [ESX VSCode](https://marketplace.visualstudio.com/items?itemName=Knoblauchbrot.esx-vscode)
Proširenje koje ukljućuje ESX funkcije i varijable.
Napravljeno od strane Knoblauchbrot.

## Kreiranje prve ESX skripte
Osnovna FiveM skripta sadrži par foldera i fileova.

### Osnovna struktura skripte
<FileTree>
  <FileTree.Folder name='MojaSkripta' defaultOpen>
    <FileTree.File name="client.lua" />
    <FileTree.File name="server.lua" />
    <FileTree.File name="config.lua" />
    <FileTree.File name="fxmanifest.lua" />
  </FileTree.Folder>
</FileTree>

### Primjer `client.lua`
```lua
-- Koristimo native RegisterCommand od FiveM-a jer ESX-ov ESX.RegisterCommand ne postoji na client strani
-- Ova komanda ne postoji na server strani tako da je nećeš moći koristiti iz konzole.
RegisterCommand('clientTest', function ()
  print(Config.cool)
  if ESX.IsPlayerLoaded() then
    print("Igrać je već učitan")
  else
    print("Igrać nije učitan")
  end
end, false)
```

### Primjer `server.lua`
```lua
-- Funkcija od ESX-a koja je napravljena da bih olakšala kreiranje komandi
-- Za više informacija o njoj idi na docs stranicu o ESX.RegisterCommand funkciji
ESX.RegisterCommand('test', 'user', function(xPlayer, args, showError)
  print(xPlayer.getName() .. " ima posao " .. xPlayer.job.label)
  print(Config.cool)
end, true, {help = 'Koji posao ima igrać'})
```

### Primjer `config.lua`
```lua
Config = {
    cool = "Ovo je neka varijabla u konfigu"
}
```

Primjer `fxmanifest.lua`
```lua
-- Ovaj file je potreban u svakoj FiveM skripti

fx_version 'cerulean'
game 'gta5'

description 'Moja zanimljiva skripta'
author 'Tvoje ime'

lua54 'yes' -- Nije uvijek potrebno, ali je dobro staviti

-- Fileovi koji su potrebni i na server i na client strani
-- NE STAVLJAJ WEBHOOKOVE I API KEYEVE U TE FILEOVE.
shared_scripts {
    'config.lua' -- Nije potrebno ali je dobro da ne hardcodeaš sve.
}

client_scripts {
  'client.lua',
}

server_scripts {
  'server.lua',
}

shared_scripts {
  '@es_extended/imports.lua', -- Importa ESX objekt i PlayerData objekt
  '@es_extended/locale.lua', -- Importa prijevode
}

dependencies {
  'es_extended' -- Stavljaš da osiguraš da se skripta starta nakon es_extended.
}
```
