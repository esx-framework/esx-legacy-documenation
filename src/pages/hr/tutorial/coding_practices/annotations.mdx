# Anotacije
Anotacije su važne za lintanje. Pomažu linteru da razumije što funkcija treba vratiti, što funkcija radi i koji bi parametri trebali biti. To vam pomaže pronaći greške i potencijalne probleme u vašem kodu.

Ovaj dio će pokriti anotacije Lua koda koristeći Lua VSCode ekstenziju od sumneko-a. Ali samo dijelove. Za potpuni popis anotacija, možete provjeriti [Lua Language Server Documentation](https://luals.github.io/wiki/annotations/)

## Potpisi funkcija
Potpisi funkcija su važni za lintanje. Pomažu linteru da razumije što funkcija treba vratiti, što funkcija radi i koji bi parametri trebali biti. To vam pomaže pronaći greške i potencijalne probleme u vašem kodu.

**Ovako se piše potpis funkcije u Lua::**
```lua
--- Komentar koji objašnjava što funkcija radi
---@param param klasa/tip Objašnjenje parametra
---@param param2 klasa/tip Objašnjenje parametra
---@return klasa/tip varijablaNaziv Povratni rezultat
function functionName(param, param2)
    -- Vaš kod ovdje
    return 
end
```
--
**Evo primjera potpisa funkcije:**
```lua
--- Zbraja dva broja
---@param num1 number Prvi broj
---@param num2 number Drugi broj
---@return number sum Zbroj oba broja
function addNumbers(num1, num2)
    -- Izračunaj zbroj num1 i num2
    local sum = num1 + num2

    -- Vrati zbroj
    return sum
end

addNumbers(5, 10) -- Vraća 15
```

**Ovako se piše klasa u Lua:**
```lua
---@class ClassName
---@field field1 klasa/tip Opis field1
ClassName = {
    field1 = nil, -- Postavi zadanu vrijednost
}

--- Opis
---@param param1 bilo što
---@param param bilo što
function ClassName.function(param1, param)
    
end
```
