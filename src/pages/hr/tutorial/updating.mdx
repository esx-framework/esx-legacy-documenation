# Update-aj svoje skripte
Među starim verzijama ESX-a i novim verzijama, ubaćene su velike promjene ukljućujući:
- Promjena inventory sistema sa limit sistema na weight sistem
- Promjena `esx:getSharedObject` eventa u `getSharedObject` export ili import u fxmanifest-u.


## Updateanje getSharedObject-a
Da bih napravio da nova metoda radi, moraš izbrisati staru.
I onda ubaciti import ili export da bih povukao ESX objekt

Provjeri da ti se skripta starta **nakon** es_extended-a i drugih core skripti.

### Brisanje stare metode
Postoji razlika između stare metode u client strani i u server strani.
Ispod su primjeri starih metoda. 
Ako primjetiš ovaj kod negdje obriši ga i zamjeni sa metodama ispod.

Obriši svaki `ESX = nil`

#### Client strana
```lua
ESX = nil

Citizen.CreateThread(function()
    while ESX == nil do
        TriggerEvent('esx:getSharedObject', function(obj) ESX = obj end)
        Citizen.Wait(0)
    end
end)
```

#### Server strana
```lua
ESX = nil

TriggerEvent('esx:getSharedObject', function(obj) ESX = obj end)
```

### Export metoda
Ova metoda je perfektna ako trebaš samo ESX objekt.

Da bih je iskoristio samo napraviš ovo:
```lua
ESX = exports['es_extended']:getSharedObject()
```

### Import metoda
Ova metoda je ista kao export metoda ali dodaje event listener i funkciju koja provjerava jel ESX.PlayerData updatean.

Da iskoristiš ovu metodu samo ubaci ovo u client ili server stranu u fxmanifestu:
```lua
'@es_extended/imports.lua'
```
