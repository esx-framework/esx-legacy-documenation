<div style = {{ fontSize: '40px', fontWeight: 'bold' }}>Bienvenue dans la documentation ESX.</div>

Ceci est la documentation officielle pour la Framework ESX. La Framework ESX est un projet open source qui vise à être la meilleure Framework de tout FiveM. Apprenez-en plus ci-dessous sur comment l'utiliser.

Peu importe votre expérience dans le développement de scripts fivem, nous avons ce qu’il vous faut !

## Introduction

### Votre premier serveur
Nous avons un tutoriel détaillé sur comment créer un Serveur FiveM avec  ESX. Jeter un coup d’œil au [Guide d'installation](fr/tutorial/install)

### Votre premier Script
Créez votre premier script pour FiveM avec ESX en suivant notre [Guide de développement](fr/tutorial/developing)

## Dépannage
Vous rencontrez des problèmes pour créer votre serveur ESX fivem ou un script? Consultez la page de [Dépannage!](fr/troubleshoot)

Toujours des problèmes ou quelque chose n'est pas claire? Rejoignez  notre [Discord](https://discord.esx-framework.org/) et obtenez de l'aide de notre staff et des autres  membres de la communauté.
